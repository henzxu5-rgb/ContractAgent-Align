# 方法与结论边界

## 任务与研究问题

输入一份英文 NDA 与一个固定陈述，Agent 在当前合同内检索、阅读，提交 Entailment / Contradiction / NotMentioned 及证据片段。BM25 不训练；每任务最多六次读取或检索；提交只允许引用实际观察过的片段。全文和标注分开存储，行动上下文使用字段白名单，不含参考答案或测试反馈。

核心比较：在相同基础模型、SFT 起点、上下文、自然候选池和训练配置下，普通 LLM Judge 偏好与加入标签/证据验证的偏好，是否带来不同的训练结果？两组 DPO 共享最终 88 对候选，只改变优胜标签，其中 17 对标签不同。

## 数据与标注生产

保留 ContractNLI 官方 423 / 61 / 123 合同级划分，按归一化文本检查完全重复，隔离跨集重复训练合同 538。固定 seed=20261015；从测试侧按合同 ID 盲抽 20 份，评测全部 17 个陈述，共 340 任务。初始 200 个训练任务覆盖 160 份合同；教师任务扩至 236，最终保留 120 条示范，覆盖 111 份合同。测试不参与筛选与配置调试。

教师实际执行后，按完成提交、标签一致、参考证据集合一致和已观察引用筛选；120 条轨迹拆为 674 条状态/下一动作样本。SFT 仅监督 assistant 行为，工具返回作为上下文，超长样本显式排除并计数。

偏好从 SFT 策略的训练任务状态出发，同一上下文采样两个下一动作，在相同环境状态分别真实续跑。总 400 对包含相同动作、双错和平局/拒判；共同保留 88 对，覆盖 78 任务，其中 65 对工具名/参数不同。候选池由旧温度 0.7 的 67 对与温度 1.2 的 333 对组成，是有记录的可行性调整，不能推断温度因果效果。

## Judge 与验证流程

Rubrics 依次关注陈述判断、证据支持与引用有效性、工具决策、正确前提下的冗余。普通 Judge 不见标准答案；验证后流程结合参考标签、证据 F1、提交有效性以及交换 A/B 顺序后的稳定性，允许平局和拒判。参考证据不一定穷尽合理证据，无法确定的语义争议没有被冒充为新增人工审核。

共同偏好池避免把增加样本量误认为标注方式的效果。400 对候选全部计入统计，拒判率 77.5%；顺序判定不一致率 22.5%，包含 A/B 与 tie/abstain 间的变化，不等于全部是 A/B 优胜反转。详见 Judge 审计及 SOP。

## 训练设置

- 基础模型：`Qwen/Qwen3-4B-Instruct-2507`，revision `cdbee75f17c01a7cc42f958dc650907174af0554`。
- 单卡 FP16 NF4 QLoRA，rank 16、alpha 32、dropout 0.05；最大序列 4096，micro-batch 1、梯度累积 16。
- SFT：学习率 1e-4、两轮、86 次有效更新；两组 DPO 从同一 SFT 出发，学习率 5e-6、beta 0.1、一轮、各 6 次有效更新。
- DPO 固定 SFT 参考模型并预计算参考概率；检查两组初始策略/参考相同、参考不更新、最终策略变化及适配器可重载。数量较小限制了收益判断。
- 技术验收适配器与开发侧样本不进入正式效果比较。

## 独立评测

五个条件为基础 Agent、SFT Agent、普通 Judge DPO、验证后 DPO、基础模型全文回答；各执行同一 340 任务。全文上下文上限 16384，工具 Agent 为 4096；正式推理统一 batch cap 16。滚动观察窗口及工具配置不变。

主指标为三类 Macro-F1，辅助包括各类 F1、证据 P/R/F1、无效引用尝试、工具错误、调用数和用量。证据指标只在参考支持/反驳的 204 任务统计；136 个未提及任务不以空证据抬高分数。失败与未提交保留在主分母。按 20 份合同进行配对聚类 bootstrap，1000 次重采样。

**SFT 的 Macro-F1 提高 20.98 个百分点，包含协议遵循与完成率改善。验证后 DPO 未获额外收益。** 未达到相比 SFT 至少 +3 个百分点、证据 F1 不下降超过 2 个百分点且无效引用不恶化的继续门槛，停止扩量。

## 限制

1. 固定陈述、20 份未见合同与单训练种子；bootstrap 不包含重新训练的方差，不能声称跨种子稳定。
2. 未新增法律专家或人类偏好标注；AI Judge 与程序一致性检查不证明法律说明充分。
3. 评测恢复更换硬件：基础/SFT 与普通 DPO 前 142 任务在 RTX6000D，普通 DPO 剩余 198 及验证后 DPO 全部 340 任务在 RTX PRO 6000 Blackwell。权重哈希、软件与批量上限一致，硬件和实际批次组成不同，小幅差异不构成严格受控的因果证据。
4. 没有 Judge 与纯程序偏好的独立消融；不能证明 Judge 本身优于规则。公开数据预训练污染与近重复风险不能排除。
5. 本项目的协议与子集结果不是 ContractNLI 官方 Agent 榜单成绩，不外推为任意法律咨询能力。
